# Learning session records

Create one small Markdown file per real Kevin learning session:

`YYYY-MM-DD-topic-slug.md`

Do not generate a session record merely because an agent changed code.

## Template

```markdown
# Session: topic

- Date/time: YYYY-MM-DDTHH:MM:SS+03:00
- Course path:
- Official assignment/source:
- Starting learning state: unknown | present | runnable | verified | explained | mastered
- Energy/capacity: low | medium | high (optional)

## Recall
What Kevin remembered before reading:

## Prediction
What Kevin expected and why:

## Run evidence
Exact command and observed result:

## Explanation in Kevin's words

## Small refactor/test
What changed, if anything, and why:

## Misunderstanding corrected

## Evidence references
- Repository path/test/commit:

## Resulting learning state
State and justification:

## Next review
Date and one bounded prompt:
```

Keep private health, credentials, raw LMS data, and unrelated personal notes out of this repository.

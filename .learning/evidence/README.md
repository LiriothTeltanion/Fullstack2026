# Learning evidence records

Evidence supports a specific state for a specific path. It does not certify an entire week by association.

## Acceptable repository evidence

- exact command plus exit/result;
- deterministic automated test tied to an assignment behavior;
- manual browser/CLI/SQL checklist with date, environment, and observed result;
- screenshot or recording of real output with private data removed;
- code review that identifies requirement, edge cases, and limitations.

## Acceptable learning evidence

- Kevin's own explanation of the key idea and trade-offs;
- prediction before execution and correction afterward;
- independent reproduction or adaptation after time has passed;
- a small debugging task completed with the level of assistance disclosed.

## Insufficient evidence by itself

- a file or README exists;
- static syntax passes;
- an AI wrote the solution/explanation;
- a commit, badge, generated score, or green CI job exists;
- a project looks polished;
- another exercise in the same week has tests.

## Record format

Use `YYYY-MM-DD-path-slug.md` and include:

- target path;
- repository state and learning state;
- official requirement/source status;
- commands/results;
- what the evidence proves;
- what it does not prove;
- AI assistance disclosure;
- next review date.

Never include tokens, passwords, private LMS session data, personal health notes, or fabricated impact.

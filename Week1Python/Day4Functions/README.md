Day 4 was all functions: parameters and default values, `return`, scope, `*args`, and breaking a bigger task into small pieces. Each exercise is one script with nothing outside the standard library.

## Contents

| Folder | What it is |
|--------|------------|
| [`Exercises/ExercisesXP/`](Exercises/ExercisesXP/) | Seven warm-ups: defaults, keyword arguments, `random`, changing a list inside a function, a weather report |
| [`Exercises/ExercisesXPGold/`](Exercises/ExercisesXPGold/) | A retirement check with dates, X + XX + XXX + XXXX and a dice simulation |
| [`Exercises/ExercisesXPNinja/`](Exercises/ExercisesXPNinja/) | Capitalized names, Morse code, a box of stars with `*args` and an insertion sort |
| [`Exercises/TimedChallenge1/`](Exercises/TimedChallenge1/) | How many times a character shows up in a string |
| [`DailyChallenge/SolveTheMatrix/`](DailyChallenge/SolveTheMatrix/) | A grid of characters read column by column to find a sentence |
| [`DailyChallenge/CoffeeShopMenuManager/`](DailyChallenge/CoffeeShopMenuManager/) | A coffee shop menu in the console, one function per action, with 19 tests |

# Demo Day Presentation

My outline for presenting the capstone. Total time: **5 minutes** plus questions. I fill in every `_…_` line,
then rehearse with a timer at least three times.

## Timing

| Part | Time | Slide |
|---|---:|---|
| Hook and problem | 0:30 | 1–2 |
| The solution in one sentence | 0:20 | 3 |
| Live demo | 2:30 | 4 |
| How it works (stack and one hard part) | 1:00 | 5–6 |
| What I learned and what is next | 0:30 | 7 |
| Thank you and links | 0:10 | 8 |

## Slides

### 3. My solution

### 4. Live demo (the main part)

I follow one user story from start to end. I log in with a demo account that already has data.

1. _Open the home page and say what the visitor sees._
2. _Sign up or log in._
3. _Create something (the main feature)._
4. _Edit or search it._
5. _Show the result that solves the problem from slide 2._

Backup: a 60-second screen recording of the same flow, in case the network or the server fails.

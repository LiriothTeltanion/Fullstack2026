# Font Awesome Free brand icons

This page bundles the unmodified **GitHub** and **LinkedIn In** SVG icons from **Font Awesome Free 6.7.2**, by **Fonticons, Inc.**

| Local file        | Upstream source                                                                                       |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| `github.svg`      | [GitHub SVG](https://github.com/FortAwesome/Font-Awesome/blob/6.7.2/svgs/brands/github.svg)           |
| `linkedin-in.svg` | [LinkedIn In SVG](https://github.com/FortAwesome/Font-Awesome/blob/6.7.2/svgs/brands/linkedin-in.svg) |

The SVG icons are licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). Their embedded attribution comments are retained, and the original [Font Awesome Free license](LICENSE.txt) is included locally. The brand marks identify the linked services; they do not imply endorsement.

The icon images are decorative because each link already has a visible service name and an accessible label. They load from this directory and require no third-party requests.

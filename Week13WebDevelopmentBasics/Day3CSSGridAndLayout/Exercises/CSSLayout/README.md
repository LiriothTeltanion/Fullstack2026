Fieldnotes is a small project index with a responsive header, navigation, cover, project gallery and footer. Its links point to exercises in this repository.

## ▶️ How to run

Open [index.html](index.html), or serve the repository with `npm run dev` and navigate to this folder. The page uses local assets and system fonts.

## Layout choices

- Flexbox arranges the navigation, header, footer and the content inside each card.
- CSS Grid makes the project gallery responsive using auto-fit and minmax.
- The narrow-screen header stacks and the navigation links wrap.
- A skip link and visible focus outlines support keyboard use.
- Reduced-motion settings disable the hover movement and smooth scrolling.

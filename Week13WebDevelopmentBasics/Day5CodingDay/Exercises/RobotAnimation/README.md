# 🤖 Exercise - Robot Animation

<img src="../../../../assets/readme/folder-pulse.svg" width="100%" alt="Animated learning pulse">

A robot drawn with CSS boxes, rounded corners and pseudo-elements. Hovering over it or focusing it with the keyboard makes its head, arm and legs move.

## ▶️ How to run

Open [index.html](index.html) in a browser. All assets are local. Use Tab to focus the robot and move focus away to stop the animation.

## What the files do

- [index.html](index.html) gives the robot a head, eyes, torso, arms and legs, plus an accessible description.
- [style.css](style.css) composes the shapes and runs the hover and focus animations.
- The reduced-motion media query disables the animations.

The head grows on hover or keyboard focus while the robot waves and moves its legs. The exercise uses an original visual treatment with the requested CSS anatomy and interactions.

## Checks

Keyboard focus activates the same CSS selector as hover. A reduced-motion rule disables animation. Browser visual review is recorded separately from source checks.

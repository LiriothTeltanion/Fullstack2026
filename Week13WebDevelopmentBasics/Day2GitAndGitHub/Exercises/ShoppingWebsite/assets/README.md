# Image credits and licenses

The thirteen SVG product illustrations in `products/` are original vector artwork created for this Riff Shop exercise. They depict generic music accessories, contain no third-party logos or photographs, and are available under the repository's MIT license. Each image has an SVG title/description and a descriptive HTML `alt` attribute in the catalog.

`fontawesome/guitar.svg` is the **guitar** icon from **Font Awesome Free 6.7.2**, copyright Fonticons, Inc. The SVG icon is licensed under **Creative Commons Attribution 4.0 International**. Its original license comment is retained, and the complete distribution license is included in [fontawesome/LICENSE.txt](fontawesome/LICENSE.txt).

The decorative brand icon uses an empty `alt` because the adjacent Riff Shop name supplies the link's accessible name. Product images have their own descriptive alternatives. No remote font, image API or CDN is needed at runtime.
